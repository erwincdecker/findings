# Homelab Functional Capability Map

| Capability domain | What it does | Public documentation |
| --- | --- | --- |
| Virtualization and availability | Runs isolated workloads and coordinates recovery | [Compute](../infrastructure/compute/README.md) |
| Storage | Provides file shares and persistent block storage | [Storage](../infrastructure/storage/README.md) |
| Backups and recovery | Protects data and verifies restoration | [Recovery](../infrastructure/backup-recovery/README.md) |
| Network and ingress | Exposes selected applications through controlled routing | [Ingress](../networking/ingress/README.md) |
| Threat monitoring | Classifies security signals and supports safe incident response | [Security](../security/README.md) |
| Media automation | Downloads, identifies and imports music and video | [Media](../media/README.md) |
| Photos and documents | Manages personal application data and sharing | [Applications](../applications/README.md) |
| Container operations | Runs, updates and observes service containers | [Containers](../platform/containers/README.md) |
| Events and integration | Delivers durable events between services | [Integration](../integration/README.md) |
| Agent coordination | Delegates bounded tasks with explicit authority | [Agents](../automation/agents/README.md) |
| Change governance | Controls impact, rollout and review | [Operations](../operations/README.md) |
| Engineering and QA | Verifies changes against observable acceptance criteria | [Quality](../engineering/quality/README.md) |

**Scope:** Functional design and learned practices only. Private topology, inventory, logs and credentials are intentionally omitted.
