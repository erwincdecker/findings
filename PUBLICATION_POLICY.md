# Publication policy

This repository contains English-language, public-safe technical findings, architectural patterns and community feature proposals.

## Publish
- General design descriptions and engineering lessons.
- Synthetic examples and non-sensitive acceptance tests.
- Clear status labels: DOCUMENTED, PROPOSED, OBSERVED, NOT VERIFIED.
- Links to public upstream documentation.

## Do not publish
- Credentials, tokens, private keys or certificates.
- Internal network addresses, private hostnames, production configuration or authentication details.
- Raw operational logs, data exports, personal files or private source code.
- Unsupported claims that a change has been tested or deployed.

## Workflow
Review and sanitize documentation before publication. Keep private system evidence in its original restricted storage. Publish results only after a public readback check.

This repository is documentation and does not grant runtime execution authority.
