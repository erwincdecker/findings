# Media Automation and Arr Applications

**Status: DESIGN AND QUALITY PRACTICES.**

Media automation separates discovery, indexer integration, download-client handoff, matching, import and organization. Music and video applications share general workflow patterns but differ in matching rules and release identities.

Key checks include download categories, path mappings, import rejection messages, duplicate detection, seeding policy and correct library placement. A download marked complete by its client is not automatically a successful library import.

For the specific partial-album proposal, see the [music area](../../music/README.md).
