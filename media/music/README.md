# Music and Library Automation

**Status: DOCUMENTED FINDINGS AND FEATURE PROPOSALS.**

Music automation includes discovery, download management, album matching, track identification, import and native completed-download handling.

Important distinction: identifying individual audio tracks is not the same as matching an entire complete album edition. Incorrect artist or release mappings must never be accepted merely to work around missing tracks.
